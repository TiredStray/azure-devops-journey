## 🛠️ Infrastructure Projects Overview

### 01. Linux Automation (August 2026)
*   **Objective:** Re-master system-level resource tracking and access controls.
*   **Implementation:** A lightweight Bash utility parsing CPU, memory metrics, and disk trends. Enforces strict `chmod 700` filesystem encryption-at-rest layouts for logging storage.

### 02. Public API Log Ingestor (September 2026)
*   **Objective:** Apply structured Python paradigms to automate data system tasks.
*   **Implementation:** An asynchronous script leveraging the `requests` library to query external registries, isolate payload schemas, and write data blocks into cleanly formatted YAML/JSON structures.

### 03. Secure Enterprise VNet Topology (October 2026)
*   **Objective:** Blueprint cloud networks based on zero-trust and least-privilege access models.
*   **Implementation:** Architectural patterns separating public web endpoints (DMZ) from confidential internal backend networks using strict Azure Network Security Groups (NSGs).

### 04. Sustainable "Green Ops" Scheduler (November 2026)
*   **Objective:** Programmatic infrastructure life cycle handling aligned with climate-conscious commitments.
*   **Implementation:** A cloud management utility utilizing `azure-identity` and `azure-mgmt-compute` Python SDKs to query local regions, track usage, and spin down inactive dev/test nodes outside operating intervals.

### 05. Codified Enterprise Topology (December 2026)
*   **Objective:** Eliminate manual click operations by migrating networks completely to Infrastructure as Code (IaC).
*   **Implementation:** Modular Terraform configurations spinning up identical cloud resources securely while strictly maintaining local state isolation via `.gitignore`.

### 06. Automated Pipeline Integration (January 2027)
*   **Objective:** Guarantee application performance and security standards before pushing to cloud systems.
*   **Implementation:** GitHub Actions integration running automatic Python linters and code checkers over cloud manifests on every branch update.

### 07. Containerized Internal API (February 2027)
*   **Objective:** Build secure, reliable microservice images with zero external dependencies.
*   **Implementation:** Multistage Docker builds compiling code down onto secure, non-root Alpine Linux platforms to minimize attack profiles.

### 08. High-Availability Microservice Cluster (March 2027)
*   **Objective:** Run container pipelines across enterprise-scale infrastructure.
*   **Implementation:** Declarative Kubernetes configurations orchestrating self-healing deployment models behind elastic Azure Kubernetes Service (AKS) load-balancing layers.

### 09. Canadian Compliance & Sovereignty Guardrails (April 2027)
*   **Objective:** Enforce compliance constraints required by public health networks and government agencies.
*   **Implementation:** Custom JSON Azure Policy injections that block any infrastructure builds originating outside localized Canadian geographic centers (`Canada Central` / `Canada East`).
